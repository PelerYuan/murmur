# Murmur

自托管的全天"环境秘书"。USB 麦克风持续录音，语音转文字并区分说话人，再由大模型生成摘要和待办。全部跑在你自己的硬件上，通过仅限局域网的网页端查看。

> 状态：规划中。设计与路线图见 [docs/PLAN.md](docs/PLAN.md)。[English](README.md)

## 设计目标

- **每一层都可替换**：录音端、音频存储、语音转文字服务、LLM 分别配置。STT 可以部署在另一台机器，LLM 是任意 OpenAI 兼容 API。
- **说话人是一等公民**：自动聚类声音，在网页上命名、合并、拆分或忽略；命名后的声音之后自动识别。
- **音频不久留**：转写落库校验后立即删除原始音频，只保留声纹向量和每个说话人的少量短样本。
- **组件隔离**：`recorder`、`core`、`asr`、`web` 之间只用 HTTP 通信，可分开部署。

## 路线图

M0 实测 → M1 采集与转写 → M2 说话人 → M3 摘要与待办 → M4 网页端 → M5 部署。详见 [docs/PLAN.md](docs/PLAN.md)。
